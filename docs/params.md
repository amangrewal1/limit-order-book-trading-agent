# Adaptive Agent Parameters

| Param | Default | Notes |
|---|---|---|
| `take_threshold` | 1.2 | OFI z-score to trigger market-take |
| `base_spread_ticks` | 4 | Base quote spread |
| `inventory_cap` | 100 | Max position before skew overrides quote |
| `skew_coef` | 0.5 | Inventory-skew intensity |
| `window` | 50 | OFI rolling window size |
